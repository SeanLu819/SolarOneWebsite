## ⏳ 待部署操作（需您在 Vercel 控制台完成）

### #2b — 在 Vercel 配置 `SECRET_KEY` 环境变量

> ⚠️ **必须完成**，否则生产部署会因 `ImproperlyConfigured` 拒绝启动（有意设计）。

- 强随机密钥已生成，保存在本地 `_secret_key.txt`（已被 .gitignore 忽略，**请打开该文件复制密钥**）
- **操作路径**：Vercel 控制台 → Project → **Settings → Environment Variables**
  - Name: `SECRET_KEY`
  - Value: 上面密钥（注意 `*`、`#`、`+` 等字符不要被编辑器转义）
  - Apply to: **Production**（建议同时加到 Preview / Development）
- **CLI 方式**（需先安装 Node.js + `npm i -g vercel` 并 `vercel login`）：
  ```bash
  vercel env add SECRET_KEY production
  vercel env add SECRET_KEY preview
  vercel env add SECRET_KEY development
  ```
- **验证**：部署后访问任意页面，确认 500 错误消失；或 `vercel env ls` 看到记录。
- ⚠️ **配置完成后请删除本地 `_secret_key.txt`**（见 N-23）

2. 若需留存备份，放入密码管理器而非仓库目录
3. 顺带清理其余 28 个 `_*` 临时文件（#19）

### 🟠 N-24 无 CI / 无依赖漏洞扫描

**现状**：仓库无 `.github/workflows/`，`pip audit` 与 Dependabot 均未启用。当前依赖（`django>=6.0`、`deep-translator`、`user-agents` 等）无自动化漏洞监测。

**建议**：
1. 加最小 CI：push/PR 时跑 `pip install -r requirements.txt && python manage.py test`（现有 28 个用例）
2. 启用 Dependabot alerts 或加一步 `pip audit`
> 与 `docs/优化建议清单.md` N-25 为同一项，此处强调其**安全**属性。

### 🟡 N-25 未配置 Content-Security-Policy（CSP）

**现状**：已配置 HSTS / `SECURE_CONTENT_TYPE_NOSNIFF` / `SECURE_REFERRER_POLICY` / `X-Frame-Options`（`XFrameOptionsMiddleware` 默认 DENY），**但未配置 CSP**。

**难点**：站内有大量内联 `<script>` 与内联 `<style>`（`base.html` 内嵌主题切换、轮播、Cookie 横幅、后台动态 `:root` 等），直接上严格 CSP 会大面积破坏功能。

**建议（分两步）**：
1. 先加 `Content-Security-Policy-Report-Only` 观察一段时间，收集实际内联资源清单
2. 再决定：是给内联块加 `nonce`（改动大），还是接受较宽松的策略（如允许 `unsafe-inline` 但限制 `default-src` 与 `frame-ancestors`）
> 优先级低于其他项：**当前 XSS 面已由 #8/#9/#10/#11 的转义与校验覆盖**，CSP 属纵深防御。

### 🟡 N-26 生产环境访客统计未启用（功能与合规的取舍）

**现状（2026-09-08 核查）**：
```python
if not IS_VERCEL:
    MIDDLEWARE.append('pages.middleware.VisitorTrackingMiddleware')   # 仅本地挂载
```
→ Vercel 生产**未挂载**访客追踪中间件。

**双面影响**：
- ✅ **正面**：无意中规避了"每次 GET 写 SQLite"的性能问题（Vercel 上 SQLite 在 `/tmp`，写放大且随冷启动丢失）
- ⚠️ **负面**：生产 `Visitor` / `DailyStats` 数据恒为空，后台统计功能实际不可用

**建议**：明确取舍后二选一，并在文档中写明 ——
- 不需要统计：保持现状，把本地中间件降级为可选
- 需要统计：改用外部服务（Plausible / GA，无 PII），或改为 IP+日 去重的低频写入（配合 #16 的哈希 IP）
