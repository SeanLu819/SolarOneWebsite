### #12 🟨 缓存策略不一致 → **部分完成**

**现状**：
- ✅ 联系表单限流已改用 Django cache API 且 **fail-closed**（`pages/views/views_contact.py:4`、`common.py:2`）
- ❌ 产品/项目缓存仍是进程级 dict（`pages/views/enrich.py:16` `_enriched_products_cache`）

**影响判断**：Vercel 无状态下进程级 dict 缓存会在冷启动后失效重建，**不会出错，只是缓存命中率为 0**；而 seed 数据加载本身不慢，因此**实际影响有限，可降优先级**。

**建议**：维持现状；若后续 seed 数据增长导致首请求变慢，再引入外部缓存（Upstash Redis）。

**位置**：`pages/middleware.py:60` `Visitor.objects.create(...)`

**重要补充（2026-09-08 核查）**：
```python
if not IS_VERCEL:
    MIDDLEWARE.insert(1, 'whitenoise.middleware.WhiteNoiseMiddleware')
```

**建议**：明确取舍 ——
- 若不需要生产访客统计：现状即可，把本地也去掉或保留均可，文档注明。
- 若需要：改用外部分析（Plausible / GA），或改为按 IP+日 去重的低频写入。

## 新增建议（v1.1.0，2026-09-08 核查后）

> 编号 `N-xx`，与原始 `#xx` 区分。

### 🟠 N-22 `pages/seed_data.py` 3183 行 —— 已成为新的最大文件

**现状**：比当初被诟病的 `views.py`(1197 行) 还大 **2.7 倍**。当前行数 Top 5：

| 文件 | 行数 |
|---|---|
| `pages/seed_data.py` | **3183** |
| `pages/admin.py` | 1246 |
| `pages/models.py` | 925 |
| `pages/seed_sync.py` | 620 |
| `pages/views/utils.py` | 519 |

**建议**：仓库已有 `seed_data.json`（1.5MB）。优先方案是**让 `seed_data.py` 退化为 JSON 的薄加载器**，把硬编码数据外置到 JSON；其次才是按数据域拆分（products / projects / news / siteconfig）。
> 收益：数据变更不再需要改代码，且消除"改数据触发全量 Python 重载"的部署风险。

### 🟠 N-23 `pages/admin.py` 1246 行 —— 建议拆包

已注册数十个 ModelAdmin 并含自定义 action。建议拆为 `pages/admin/` 包（`__init__.py` 汇总 + 按领域分文件），风险低、收益明确。

### 🟡 N-24 `pages/views/utils.py` 519 行 —— 可再拆

拆分后仍是最大的视图模块，混装了图片清理、图库扫描、seed 路径解析三类职责。建议拆为 `utils_image.py` / `utils_gallery.py` / `utils_seed.py`。

### 🟠 N-25 无 CI —— 28 个测试未自动执行

仓库**无 GitHub Actions**（无 `.github/workflows/`）。`pages/tests.py` 现有 28 个用例，仅能手动跑。

**建议**：加一个最小 workflow，push/PR 时执行：
```yaml
- run: pip install -r requirements.txt
- run: python manage.py test
```
后续可把 `docs/三屏响应式优化方案.md` §6 的 L1/L2 挂进去做回归基线。
> 注意：若后续要迁移 `.po`（#3），需在 build 流程补 `compilemessages`。

### 🟡 N-26 根目录 29 个 `_*` 临时文件

虽已被 `.gitignore` 忽略（`_*.py` / `_*.txt` / `_*.ps1`），仍污染工作区，且混有敏感文件 `_secret_key.txt`。

**建议**：归档到 `scripts/_archive/` 或删除；**`_secret_key.txt` 在配置到 Vercel 后应立即删除**（见安全清单 N-23）。

### 🟡 N-27 `pages/views_old.py` 82KB 死代码

与 #20 同源，仍存在且被部分 grep 命中（如 `_COMPARE_IMAGE_SLUGS` 旧副本），容易误导排查。**建议删除**（已被 `pages/views/` 完全取代）。

### 🟡 N-28 前端性能：图片无 `srcset`、字体阻塞渲染

- `home.html:15-19` 三张 1920px hero 图（≈555KB）直出手机，`loading="lazy"` 因绝对定位铺满视口而**不生效**
- `base.html:25-27` Google Fonts 以阻塞式 `<link>` 加载

详见 `docs/三屏响应式优化方案.md` §2.5 的 **N-4 / N-5**（含修复方案）。
