{% comment %} Gallery carousel controller — the single source for the product detail, product series and project detail pages. Behaviour is driven by DATA, not by a per-page copy of this script: * the element is found by id (`psCarousel`), * the autoplay period comes from its `data-interval` attribute, * thumbnails are found relative to the carousel's parent. So all three pages share this file verbatim. Two divergences in the copies this replaces were dead code and are dropped here: * `product_series.html` defined a `restartAuto()` that was never called; * the `|| 3000` / `|| 4000` fallback could never fire, because every page sets `data-interval` explicitly (3000 / 3000 / 4000 respectively). NOTE: `product_series.html` is currently NOT rendered by any view — the `product_series` URL calls the `product_detail` view, which renders `product_detail.html`. The file is kept (and kept in sync with this include) as a legacy template, and several tests/E2E checks read it as source text. See the audit's A9 notes before removing it.
