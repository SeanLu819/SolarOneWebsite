How It Works
Independent card management: Each card is stored as a ProductsPageCard record, completely separate from the Product model. The card image is uploaded directly here and stored in media/products_page/ — it will never be affected by changes to product images or seed data.

To change a card: Click "Edit Card" to change the title, subtitle, image, and link URL independently.

Link URL: Set where the card links to, e.g. /products/m-series/. The frontend matches the card to the product by extracting the slug from this URL.

To change page title/subtitle: Click "Edit Page Settings" above, or go to Site Configuration in the admin sidebar.
